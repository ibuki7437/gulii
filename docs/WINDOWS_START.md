# 第一次在自己电脑上启动谷里

如果别人已经给你一个能打开的谷里网址，直接用那个网址就行，可以跳过整篇安装步骤。

## 第一步：把压缩包完整解压

1. 找到下载的 `gulii-source-v0.2.0.zip`。浏览器一般会把它放到“下载”文件夹。
2. 用鼠标右键点击压缩包，选择“全部解压缩”。解压软件也可能显示“解压到当前文件夹”。
3. 选择一个自己找得到的位置，例如“文档”里的“谷里”文件夹。
4. 等待解压完成，再打开里面的 `gulii` 文件夹。
5. 检查是否看得到 `启动谷里.cmd`、`先看这里-使用说明.html`、`dist` 和 `scripts`。看得到这些，才是接下来要使用的文件夹。

不要只把启动文件拖到桌面：它需要和其他文件放在一起。以后要移动位置，请移动整个 `gulii` 文件夹。

## 第二步：安装一次运行工具 Node.js

Node.js 是让这个网页在你的电脑上运行的小工具，不是账号，也不需要购买。只在第一次使用时安装。

1. 用浏览器打开 [Node.js 官方下载页](https://nodejs.org/zh-cn/download)。
2. 选择标有 **LTS** 的版本；不要选择 Alpha 等测试版。版本号会变化，不必和教程完全相同。
3. 操作系统选择 Windows。普通 Intel/AMD 电脑选择 x64；如果电脑明确是 ARM 机型，选择 ARM64。不确定可到 Windows“设置 → 系统 → 系统信息”查看“系统类型”。
4. 下载 **Windows 安装程序（.msi）**，不是源码压缩包。不要复制网页上的开发命令。
5. 下载完成后双击 `.msi` 文件，按安装向导操作，保留默认的安装目录和 PATH 选项。阅读并自行决定是否接受安装许可。
6. 如果向导出现额外安装原生模块编译工具的选项，运行谷里不需要这一项，可不选。
7. 安装完成后关闭安装窗口。已经打开的启动窗口也关掉，再进行下一步。无需安装 Git、Python 或其他编程工具。

## 第三步：双击启动

1. 回到解压后的 `gulii` 文件夹。
2. 双击 **启动谷里.cmd**。Windows 如果隐藏文件扩展名，可能只显示“启动谷里”，类型为 Windows 命令脚本。
3. 会出现一个文字窗口，稍等它显示“谷里已启动”。
4. 正常情况下，浏览器会自动打开。看到“国际计算工具”和“订单称重”，表示启动成功。
5. 如果浏览器没自动打开，手动打开 Edge、Chrome 或其他现代浏览器，把 `http://127.0.0.1:8080` 粘贴到顶部地址栏，按回车。不要把它当关键词搜索，也不要改成 https。
6. 使用期间保留文字窗口，可以最小化。它是让页面保持运行的窗口，不是报错。

这个地址只给这台电脑使用。把它发给别人，对方不会看到你的工具或数据。

## 第四步：先练习，再处理真实订单

1. 阅读 [新手使用指南](USER_GUIDE.md)。
2. 可以先点页面上的“先用示例数据体验一下”。它会在当前箱子里加入一个示例订单，别把示例算进真实运费。
3. 教程另附了 `examples/练习排表.xlsx`，不含真实团员信息，可照教程练习导入、称重和结算。
4. 准备录入真实订单时，点“新建箱子”，另建一个正式箱子。

## 第五步：保存和退出

1. 每次录完一批，点击侧栏“导出全部箱子备份”。屏幕较窄时，侧栏的备份按钮可能隐藏，可在“管理箱子”里点“备份全部箱子”。
2. 确认浏览器下载中出现 `.json` 备份文件，并保存到自己找得到的位置。
3. 关闭谷里网页，再关闭文字窗口。如果按 Ctrl+C 后问“终止批处理操作吗”，输入 Y 并回车。
4. 下次使用时，再双击同一个启动文件，用同一个浏览器打开同一个地址。
5. 一般会看到上次的箱子；如果没有，先别重新填写，按使用指南恢复备份。

## 打不开时，按现象查

### 双击后提示找不到 Node.js

先完成第二步。安装后关闭旧启动窗口，再重新双击。如果仍然找不到，重新运行官方安装程序检查默认 PATH 选项，或重启电脑后再试。不需要另外购买软件。

### 提示 Node.js 版本太旧

去官方页面安装当前 LTS 版，然后关掉旧启动窗口重新启动。谷里要求 Node.js 22 或更高版本。

### 提示地址已被占用

先在浏览器打开 `http://127.0.0.1:8080`，检查是不是谷里已经在运行。如果是，直接使用那个页面。若显示其他软件，先正常退出占用这个地址的软件，再启动谷里。不要为了绕过提示随意改端口：端口变化后，浏览器会把它当作不同的数据空间。

### 浏览器提示无法访问此页面

检查文字窗口是否仍然打开、地址是否完整、是否误写成 https。文字窗口如果显示错误，请保留错误内容反馈，不要反复双击许多次。

### 双击 index.html 后页面不正常

关掉这个页面，回到第三步，用“启动谷里.cmd”启动。直接双击 index.html 不等于启动完整工具。

### 旧数据不见了

先确认是否换了浏览器、浏览器个人资料、无痕模式、设备或网址。`localhost` 和 `127.0.0.1` 也不是同一个地址。找回原来的浏览器和地址，或使用 `.json` 备份恢复。

### 图片识别让我填连接码

在“图片转排表”的“识别方式”里，改选“浏览器识别（备用，准确率较低）”。连接码是给另行安装的本机 PaddleOCR 用的，这个包不包含那套配套服务。

### Windows 阻止运行

先确认文件来自你信任的项目发布者。不要关闭杀毒或浏览器安全设置。无法判断时，停止运行并把提示反馈给维护者。

## Mac 用户

Windows 的 `.cmd` 文件不能在 Mac 上使用。

1. 完整解压，安装 Node.js 官方 LTS 的 macOS 安装程序。
2. 打开“终端”，输入 `cd `，注意 cd 后面留一个空格。
3. 把解压后的 `gulii` 文件夹拖入终端，再按回车。
4. 输入 `npm start` 并回车。
5. 浏览器打开 `http://127.0.0.1:8080`，使用期间保留终端窗口。
6. 退出前先导出备份，再到终端按 Ctrl+C。
