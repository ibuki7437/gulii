## 我已经有一个能打开的谷里网址

直接用浏览器打开网址，不需要下载源码，也不需要安装 Node.js 或注册 GitHub。

下一步看 [新手使用指南](docs/USER_GUIDE.md)，从“导入自己的排表”开始。

## 我下载了这个压缩包，想在自己电脑上用

1. 右键压缩包，选择“全部解压缩”，先完整解压，不要直接在压缩包里双击文件。
2. 打开解压后的 `gulii` 文件夹。
3. 双击 **先看这里-使用说明.html**，可以像看网页一样阅读详细教程。
4. Windows 用户按教程安装一次 Node.js LTS，之后双击 **启动谷里.cmd** 即可。
5. 浏览器出现“国际计算工具”后，照教程导入练习排表；也可以先用页面里的示例数据体验。

详细步骤见 [Windows 首次启动](docs/WINDOWS_START.md)。Mac 用户见同一文档的最后一节。

## 最重要的三件事

- 重量填“克”，不是千克；单件重量只填一件的重量，程序自动乘数量。
- 每次完成一批录入后，导出全部箱子备份；Excel 运费表和核对单图片不能代替它。
- 固定使用同一浏览器和同一个地址。换设备、浏览器或网址后，要从备份恢复记录。

## 可以做什么

Excel 排表导入、按 CN 合并、商品与归属修改、单件或合称重量录入、包装和运费分摊、多箱保存与归档、跨箱查询、Excel 运费表、团员核对单图片、备注待办、图片排表识别与人工核对。

浏览器图片识别已经包含在包中；“本机 PaddleOCR”是另外安装的配套服务，这个包不包含它，初次使用请选择“浏览器识别”。
